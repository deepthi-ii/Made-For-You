# Supabase quick setup

1. Create a Supabase project.
2. In **SQL Editor**, run the full `schema.sql` script.
3. Copy the project URL and the publishable/anon key into `.env.local`.
4. Restart Vite after editing `.env.local`.

This starter uses public links and public media so gift recipients do not need accounts. This is not suitable for confidential material without a server-side access-control design. Do not expose a service-role key in frontend code.
